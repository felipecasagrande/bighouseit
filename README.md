# BigHouseIT Solutions — Website

Site institucional estático, responsivo e pronto para GitHub Pages.

## Arquivos

- `index.html` — página principal
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile, animações de entrada e ano automático
- `assets/logo-neon.webp` — logo usada no hero
- `assets/banner-linkedin.webp` — banner institucional
- `assets/og-cover.jpg` — imagem para compartilhamento social
- `assets/favicon.png` — ícone da aba do navegador
- `.nojekyll` — mantém a publicação como site estático simples
- `404.html` — página de erro
- `robots.txt` — instruções para buscadores
- `sitemap.xml` — sitemap já apontando para `https://bighouseit.com/`
- `site.webmanifest` — metadados básicos do site
- `CNAME.example` — exemplo para domínio personalizado
- `DEPLOY_GITHUB_PAGES.md` — passo a passo de implantação

## Como editar

Você pode alterar textos diretamente em `index.html`.
As cores principais ficam no início de `styles.css`, dentro de `:root`.
